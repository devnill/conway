### Fixed

- **`Ctrl-C` did nothing while a permission prompt was on screen.** The prompt's own key handler swallowed every chorded key, `Ctrl-C` included, before it ever became the universal "stop this" action — a session sitting on a prompt the operator did not want to answer had no way out but to actually answer it or quit the whole process. `Ctrl-C` now denies the pending call (and anything else queued behind it for the same agent, which would never be decided either way once that agent's turn is aborted) and aborts the session's current reply, keeping the session live — exactly what `Ctrl-C` already does everywhere else. `Ctrl-D` now quits from this prompt too, same as every other modal. Neither bypasses the typeahead guard's own intent: `Ctrl-C` was never ambiguous with ongoing typing in the first place.
- **An aborted turn could not interrupt a call already blocked on the permission gate.** `PermissionBroker::decide` ran unraced ahead of the tool runner's own cancellation point, so a pending decision kept the agent's turn alive indefinitely even after `SessionHandle::abort_turn`/`cancel` tripped its token — the TUI fix above only ever covered the one prompt currently on screen. `decide` is now raced against the same per-turn cancellation token at its one production call site; losing that race resolves the call as denied within a bounded time and records a `permission_decision` tagged with the new `aborted` source, rather than leaving the wait unbounded.
