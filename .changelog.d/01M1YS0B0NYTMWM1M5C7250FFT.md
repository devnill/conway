### Added

- **First run warns when the chosen model's window cannot comfortably carry conway's default install** — board item `01M1YS0B0NYTMWM1M5C7250FFT`. The moment guided setup learns a model's context window (by discovery, by a typed answer, or from a provider's own verified baseline), it now estimates the fixed cost of what it is about to install — registered tool schemas and instruction fragments for the six-plugin default opinion set (measured for real, off the actual linked plugin candidates, using the same `heuristic-chars4` estimator every `ContextReport` uses), plus a representative command-prompt allowance — and warns when that fixed cost alone would already spend more than half the window. The warning names both numbers and offers two ways out, deciding neither for the operator: point conway at a larger-window model (naming one already configured when one clears the bar), or narrow the tool set for this role.
- **`conway routes explain` shows the same fixed cost against each candidate's window** — board item `01M1YS0B0NYTMWM1M5C7250FFT`. A new `fixed_cost:` column (`--json`'s `"fixed_cost"` key) renders `<total>/<window> tokens (<pct>%)` per chain entry, flagging `, over half the window` at the identical threshold guided setup's own preflight warns at, reusing that preflight's own `default_opinion_set_footprint`/`runway_fixed_cost_warning` rather than a second implementation.

### Fixed

- **The runway notice's token units no longer double their `k` suffix** — `conway_runtime::runway`'s per-turn context-window-fill notice used to render `10.6kk of 32.7kk tokens` (the compact-`k` formatter's own suffix, appended a second time by the surrounding template) any time either number was already >= 1000 tokens; it now renders `10.6k of 32.7k tokens`.
