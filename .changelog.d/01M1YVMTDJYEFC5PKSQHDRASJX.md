### Added

- **`conway.compaction`, an installable, off-by-default plugin that folds old tool results into one ephemeral summary segment** — packages `docs/plugins/cookbook.md` example 2's `CompactOldToolResultsHook`: every turn, every `ToolResult` segment beyond the most recent `fold_after_turns` (default 1, configurable via `[plugins.config.conway.compaction]`) folds into a single labeled summary segment, carrying its own provenance naming `conway.compaction` and how many results it folded, so `/context` never shows an anonymous note where this plugin acted — and the TUI transcript shows the same notice live, the first time a request folds anything and again only when the fold count actually changes, so an operator who never opens `/context` still sees it happen. This is deliberately **the weakest form of what "compaction" usually means**: nothing persists the fold (recomputed from scratch on every single turn), no user/assistant text is ever summarized, and no model call is involved — see `docs/plugins/compaction.md` for the full caveat. Not in the default opinion set; an operator who wants it installs it explicitly.
