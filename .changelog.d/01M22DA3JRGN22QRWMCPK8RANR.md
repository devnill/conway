### Added

- **Bare `/resume`'s picker now supports typing to filter and a key to widen the listing across every project** — board item `01M22DA3JRGN22QRWMCPK8RANR`. Once the picker is open, an ordinary character narrows the visible rows to the ones whose line contains what you typed (case-insensitive, `Backspace` undoes one character at a time); `Up`/`Down`/`Enter` only ever move to or answer with a currently-visible row. `Tab` additionally merges in sessions found under every other project's own session-root key on this machine — closing the "no single view" gap for a session that still lives under an old, pre-git-root key, marking each merged row with the project key it came from. `/resume <text>` typed at the command line keeps its exact existing contract: an unresolvable id or name is still a plain, immediate error naming `conway sessions list`, never a pre-filtered picker (a deliberate difference from `/model`, since landing in the wrong session is costlier than landing on the wrong model). Closing this required one new narrow facade method, `Conway::discover_sessions_all_projects`, reaching the SAME `SessionSearchScope::AllProjects` discovery the model-facing `conway.discover` tool already used, now also reachable from the TUI.
