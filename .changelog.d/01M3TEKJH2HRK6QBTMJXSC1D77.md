### Fixed

- **An Ollama-style tagged model id (`glm-5.2:cloud`, `llama3.2:latest`, …) now resolves the same bundled per-model metadata its bare id already does** — board item `01M3TEKJH2HRK6QBTMJXSC1D77`. `ModelMetadataStore::get` previously matched only the exact or normalized id, so a real `glm-5.2:cloud` session ran against the unsourced 32,768-token `"ollama"` profile floor instead of the bundled 1,048,576-token window `glm-5.2` already declares. It now falls back from `name:tag` to `name`'s own entry when `tag` does not look like a parameter-size variant (`:cloud`/`:latest` fall back; `:8b`/`:70b`/`:27b-mlx` do not, since a different parameter count can be a genuinely different model). An explicit `models.json` entry for the tagged id itself always wins.
- **`conway.toolindex`'s index entry is now actually one line, in the sense the doc promises.** A deferred tool's description is narrowed to its first sentence, or a 100-character bound, rather than kept verbatim — a real MCP server's multi-sentence description (DOGFOOD 3 measured one at ~380 characters) no longer survives into the announced index entry. `describe_tool` still serves the full, untruncated description.
- **A not-admitted tool-result note no longer asserts that the specific tool which overflowed has `offset`/`limit` arguments it may not have.** The remedy wording now asks the model to check whether the tool itself accepts a narrower request, naming `read`'s `offset`/`limit`, `grep`'s own filter, and `web_fetch`'s `max_bytes` as illustrations — not a claim about the triggering tool specifically. Traced against a real DOGFOOD-3 incident where a `web_fetch`-produced oversized page result was correctly withheld and explained, but the generic advice did not apply to the tool that produced it.

### Changed

- **`docs/plugins/toolindex.md`** now documents the index-entry truncation fix with before/after numbers on this crate's own fixture, and a measured table of conway's own always-announced subagent tools' per-request wire cost (`conway_fork`/`conway_ask`/`conway_cancel`/`conway_spawn`/`conway_steer`, ~10,554 wire chars combined) — whether those five should themselves be shortened or made deferrable is left as an open design question for the operator.
