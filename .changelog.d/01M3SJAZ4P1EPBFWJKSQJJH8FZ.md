### Fixed

- **A `roles.<alias>.params.extra.reasoning_effort` setting no longer vanishes on an Ollama role with no explanation, and no longer crashes every turn against a model that cannot reason** — board item `01M3SJAZ4P1EPBFWJKSQJJH8FZ`. Ollama's OpenAI-compatible `/v1/chat/completions` endpoint has a genuine, typed `reasoning_effort` field (confirmed live against Ollama 0.35.0), so the built-in `ollama` profile now sends it, same as `openai`; its NATIVE `/api/chat` endpoint (used once a session has a resolved context window) reads the same `extra.reasoning_effort` value and sends it as its own `think` field, which also accepts a plain boolean for a boolean-only thinking model (`reasoning_effort` itself stays string-only: Ollama's own OpenAI-compatible endpoint 400s on a non-string there). Both wire names are now additionally gated per MODEL: a model `models.json`/bundled metadata declares does NOT support reasoning never receives the field — skipped and warned by name — while a model with no declaration at all (confirmed the common case even for real reasoning-capable local models) still gets it, so the fix does not trade a silent no-op for a hard failure on every turn against an undescribed non-thinking model. A resulting `400` from either endpoint is now a clean, attributable message naming the model, not raw truncated JSON (Ollama's native error shape, a flat `{"error": "<string>"}`, is read correctly for the first time). Either shipped adapter (`anthropic`, `openai-compat`) now logs one `tracing::warn!` naming the field and the backend for ANY `params.extra` key it drops — not just a configured `reasoning_effort`/`reasoning_budget_tokens` a dialect does not send, but any other key with no wire mapping at all — so a setting with no effect is never silent again.

### Changed

- **`docs/routing.md`** corrects "an `extra` key a backend's own wire layer does not recognize is passed through untouched" — that was never actually true (neither adapter has a generic passthrough); the real, now-implemented behavior is warn-and-drop, matching the `seed` precedent. **`docs/providers.md`** documents the `reasoning_effort`/`think` wire-name split across Ollama's two endpoints and the per-model gating policy.
