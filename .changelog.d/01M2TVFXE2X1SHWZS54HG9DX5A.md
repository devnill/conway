### Fixed

- **A fallback caused by an admission-time skip is no longer silent, and `/why` no longer answers it with an empty `after:`** — board item `01M2TVFXE2X1SHWZS54HG9DX5A`. When a chain's head is refused before any request is sent — its context window cannot hold the prompt plus the role's reserved headroom — routing moves to the next candidate. That skip produces no attempt and therefore no attempt failure, so the routing reason carried nothing to show: the model changed mid-session with no notice on the turn, and `/why` printed `reason: fallback #1 after:` with nothing following it. The skip is now recorded as a skip: a new `RoutingReason::HeadroomSkip` carries the candidate's own window, the prompt estimate, the headroom, and the shortfall, and `RoutingReason::Fallback` carries a `skipped` list beside `after` so an admission refusal is never written down as an attempt that failed. The mid-turn notice fires for it, and `/why` and `conway routes explain` render it through one shared formatter, so all three word the same shortfall identically.

### Changed

- **`RoutingReason::Fallback` gained a `skipped` field, and `RoutingReason` gained a `HeadroomSkip` variant.** Both are additive: `skipped` defaults to empty when a session journal written before this change is read back, and the enum is already `#[non_exhaustive]`. `conway-runtime`'s attempt engine no longer synthesizes an `AttemptFailure` for a candidate it never dialed — those refusals move to `Fallback::skipped`, and the `ModelDecision` event now carries the enriched reason rather than the router's untouched one.
