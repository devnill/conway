### Added

- **`/goal`: a standing goal that survives twenty turns — board item `01M1YVVT9RYWZWAZC4YH21T3HN`** — a long run drifts: after enough turns of exploring and backing out of dead ends, neither the model nor the operator can see the objective from the transcript alone. `/goal <text>` sets a single sentence the focused agent is reminded of near the end of its context on every subsequent turn (`Standing goal: <text>`); bare `/goal` shows the current one, read directly from the agent's own history; `/goal clear` removes it. `/goal` is a BUILT-IN TUI command, deliberately not namespaced to a plugin — the removable half (the context segment and a `goal` status-line entry) lives in the new first-party `conway.goal` plugin (`crates/conway-plugin-goal`), in the default opinion set and inert until `/goal` is actually used; uninstalling it makes `/goal` say so instead of silently storing a goal nothing reads. The goal is persisted as an ordinary system-note record directly on the agent's own log (`SessionHandle::append_system_note`, a new, narrowest-possible facade addition — no existing call could append an arbitrary note with no live turn in flight), so it survives a `--resume` and shows up in `conway sessions show`; clearing persists its own empty-text marker so a resume never resurrects an old goal, and setting a new goal never accumulates — exactly one `conway.goal` segment is ever in any one request, regardless of how many `/goal` changes preceded it. The status line's `goal` field is tracked by the TUI itself against whichever agent is actually focused (`AppState::focused_goal`, refetched on every focus switch and written directly by `/goal` itself) rather than read from the plugin's own `status_contributions` — that method has no notion of "which agent is focused" at all, so in a multi-agent session it would otherwise show whichever agent's context was most recently built, including a background subagent's. A `/goal <text>` over 300 characters is refused, naming the limit, rather than silently truncated; the status-line value collapses a newline/tab to a space and launders every other control character before display. See `docs/plugins/goal.md` and `docs/interactive.md`'s own `/goal` section.
