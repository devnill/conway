### Fixed

- **The non-interactive guided-setup error now checks for a local model server before telling you to go get an Anthropic key** — board item `01M2M634QKE46DWNAZCB1003QN`. Under `-p`/`--print`, a pipe, or CI with no usable provider configured, conway now does the same bounded, local-only probe the interactive flow already does; if a server answers (Ollama on its default port), the printed snippet names it and the model tag it actually reported, never a guess. If nothing answers — no server, a timeout, a malformed reply — the message is byte-identical to what it always printed. The probe cannot hang the error path: it runs on a dedicated thread with its own short-lived runtime, bounded by the same timeouts the interactive probe already uses, and nothing is written to disk in either case.
