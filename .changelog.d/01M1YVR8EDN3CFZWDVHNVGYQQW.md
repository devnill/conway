### Added

- **Terminal attention notifications.** When the focused agent's turn finishes, or a permission prompt becomes visible, conway can now write a short, out-of-band signal straight to your terminal — the plain bell by default, or a richer `OSC 9`/`OSC 777` desktop notification if you opt in (`[tui.attention]` in `settings.json`; `/settings → display` shows the current config). Defaults to the bell while the terminal is unfocused — the lowest common denominator every terminal this project has had to consider renders as *something*, with zero configuration, even one that predates `OSC 9`/`777` entirely. A terminal that never reports focus changes at all is treated as unfocused, so it still gets notified. Inside tmux, `OSC` sequences are automatically wrapped in tmux's own DCS passthrough envelope; `tmux.conf` still needs `set -g allow-passthrough on` for the wrapped sequence to actually reach your terminal — `docs/interactive.md`'s new "Terminal attention notifications" section has the full per-terminal survey and the tmux note.
