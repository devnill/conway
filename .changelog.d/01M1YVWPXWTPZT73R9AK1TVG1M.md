### Added

- **`conway -p --input-format jsonl`: a persistent, stdin-driven one-shot session.** Instead of reading one prompt and exiting, conway now keeps the process open and reads newline-delimited JSON from stdin, one input per turn or operator action: `{"type":"prompt","text":...}` runs a turn on the root, `"steer"`/`"cancel"`/`"await"` map to the matching session operator actions, and `{"type":"end"}` or EOF ends the session with its documented exit code. Requires `--output-format jsonl`; a malformed line yields a driver `{"type":"error",...}` line on stdout and never stops the driver. A `"prompt"` sent while a turn is already running is queued, not rejected, and `seq` keeps climbing across turns in the same process. See `docs/scripting.md`'s "Driving conway as a persistent process" section for the full protocol and a worked Python example.
