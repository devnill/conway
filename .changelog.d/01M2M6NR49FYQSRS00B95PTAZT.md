### Added

- **A compiled-binary test harness drives `conway` attached to a real pseudo-terminal** — board item `01M2M6NR49FYQSRS00B95PTAZT`. `crates/conway-cli/tests/common/pty.rs` (`portable-pty`, the one new dev-dependency this item adds) spawns the real binary with an explicit window size, sends raw key input, waits for a pattern in the rendered output with a bounded timeout, and captures the rendered screen — the one way to exercise anything gated on `IsTerminal` (the interactive guided-setup flow, a permission-mode keypress, a slash command typed into a live session), which every other compiled-binary suite in that directory (piped `Stdio`) cannot reach. Seven new tests use it: first launch under `-p` still refuses non-interactively even with a real terminal attached; interactive guided setup detects and offers a local server in one keypress and proves it works with a real request before landing; the accepted result's `settings.json`/`models.json` land in the same config layer with an identical resolved context window from a third directory (written as a regression test — the defect it guards, `01M2M68XYD5FSCNSH2Z1BMQ399`, was already fixed); `/model` and `/role` behave as documented; and permission-mode cycling (`Shift-Tab`) changes what a flagged tool call actually does (denied outright in plan mode, run for real in auto-allow), not merely what the status line shows. `CONTRIBUTING.md` documents how to add and run one.
