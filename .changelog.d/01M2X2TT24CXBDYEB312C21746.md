### Fixed

- **A pty test that could never pass again runs once more: `three_model_switches_keep_per_turn_attribution_recoverable_via_why`** — board item `01M2X2TT24CXBDYEB312C21746`. The test paced itself between `/model` switches by awaiting `"idle"` in the status line, which is static text at a fixed column. `PtySession::screen()` is an ANSI-stripped record of what was *emitted*, not a cursor-addressed grid, and a terminal re-emits only the cells that changed, so once `idle` was on screen a later render that left those cells identical emitted nothing and a bounded `wait_for_since` could never match it again. It had only ever passed while field positions happened to shift between renders; when the layout stabilised it began timing out, against a product that was rendering correctly the whole time. It now settles on `PtySession::wait_until_settled` instead, and its `/why` assertion awaits the `routing history (` prefix and asserts the decision count separately, so "never rendered" and "count had not caught up" no longer report as the same timeout.

### Added

- **`PtySession::wait_until_settled(quiet_for, timeout)`** (`crates/conway-cli/tests/common/pty.rs`) — a settle primitive for the compiled-binary pty harness, alongside the existing `wait_for_since` (content) and `wait_for_response_to_last_send` (liveness). It blocks until the child has answered the most recent `send` and has then emitted nothing at all for `quiet_for`, and returns the byte offset one past everything emitted so far, ready to feed the next `wait_for_since` as `since`. Silence is produced by the app rather than merely true of it, so unlike a text marker it cannot be swallowed by a partial redraw. `quiet_for` is derived from the product: the app loop's 125ms animation tick advances a ten-glyph spinner while the focused agent is not `Idle`, so a busy turn cannot go quiet for two ticks, and silence past that implies `Activity::Idle` — i.e. `TurnFinished` folded, and with it every earlier envelope of the turn on the same FIFO event stream. Several pty tests in this suite invent their own settle marker; this is the one they should share.

### Changed

- **`CONTRIBUTING.md`'s pty-harness section** gains "Never settle on a marker that is merely TRUE", next to the existing partial-redraw note: why a settle marker must be something a turn newly produced, what `wait_until_settled` guarantees, why raising `quiet_for` strengthens a settle where raising a `timeout` only gives never-emitted text more time to not appear, and when to reach for each of the three waits.
