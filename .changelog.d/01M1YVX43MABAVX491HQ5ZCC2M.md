### Added

- **`tui.theme` now accepts a preset name, not only a per-slot override table.** `"tui": {"theme": "dark"}` picks one of six built-ins -- `system` (the default, plain ANSI 16 colors, unchanged), `dark`, `light`, `solarized_dark`, `gruvbox`, `nord`. A new sibling key, `tui.theme_overrides`, overrides individual named styles on top of a preset, in the same shape `tui.theme`'s own object form already uses -- an existing `settings.json` carrying a `[tui.theme]` table keeps working unchanged. `CONWAY_TUI__THEME=dark` overrides it from the environment, the same `CONWAY_TUI__*` pattern every other `[tui]` setting already follows.
- **Custom themes as files.** A file at `<config dir>/themes/<name>.json` (same per-slot shape as `[tui.theme]`'s object form) is selectable by name through the same `tui.theme = "<name>"` key -- built-in names are tried first, then this file. An unresolvable name falls back to `system` with a non-fatal startup notice naming it.
- **`NO_COLOR` and `"tui": {"color": false}` render without color.** Either strips every named style's `fg`/`bg`, keeping modifiers that carry meaning on their own -- the selection highlight and the status line's reverse-video stay exactly as visible, and the permission mode's `AUTO-ALLOW` warning gains an underline so it still reads as distinct from `plan`'s own plain bold now that color can't carry that distinction.
