### Changed

- **The TUI prompt's default keybindings now match readline/Claude Code where they overlap** — board item `01M3TEJPHQF4KHWBA6Y29Z33CY`, operator ruling (2026-09-30). The prompt gains four new rebindable actions: `prompt.line_start` (default `Ctrl-A`), `prompt.line_end` (default `Ctrl-E`), `prompt.kill_to_start` (default `Ctrl-U`), and `prompt.kill_to_end` (default `Ctrl-K`) — all four operate on the CURRENT line of a multi-line draft, never the whole buffer, (unlike readline, `Ctrl-K` at the end of a line does not join the next line). `transcript.toggle_tool_output`'s default moves from `Ctrl-E` (now claimed by `prompt.line_end`) to `Ctrl-O`, Claude Code's own key for the same affordance; an operator keymap entry for that action still wins over the new default. An unbound Ctrl or Alt chord is now ignored rather than typed as its bare letter — DOGFOOD 2 found `Ctrl-U` (unbound before this item) typing a literal `u`, turning `/` `Ctrl-U` `/settings` into `unknown command /u/settings`. Every on-screen key hint (the status-line footer's `expand` fragment, the collapsed-tool-output `… (+N lines, {key} to expand)` marker, and the `/settings` footer) now names the CURRENT effective key from `state.keybindings`, including a `keybindings.json` rebind, rather than a hardcoded literal. See `docs/interactive.md`'s "Composing input" and "Keybindings" sections.
