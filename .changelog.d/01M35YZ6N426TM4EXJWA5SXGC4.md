### Added

- **`docs/plugins/mcp.md` documents the `idempotency_key` convention any MCP tool can opt into** — board item `01M35YZ6N426TM4EXJWA5SXGC4`. Board item `01M32ECKYKN1GBP51J3Z91RA5X` taught `conway-plugin-mcp` to stamp the dispatching call's own `ToolCall::call_id` into an MCP tool's `idempotency_key` argument whenever that tool's `inputSchema` declares a property by that exact name and the caller left it unset — generic, tool-agnostic machinery any plugin author can use for retry-folding, built for ideate's `record_append` but never documented anywhere an author would find it. `mcp.md` gains a new "Idempotency: a property your tool's schema can opt into" section stating the exact property name, the opt-in-by-declaring rule, that a caller-supplied value is never overridden, what conway stamps in its place, and what a tool is expected to do with it (fold a repeat rather than duplicate) — pointing at `record_append` as the worked, already-shipped example. No code changed by this item.
