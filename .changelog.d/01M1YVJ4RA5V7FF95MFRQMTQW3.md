### Added

- **`Ctrl-G` opens the current prompt in `$VISUAL`/`$EDITOR` (falling back to `vi`)** — board item `01M1YVJ4RA5V7FF95MFRQMTQW3`. Writes the input to a temp file, suspends the TUI (leaving raw mode and the alternate screen the same way a clean exit does), runs the editor, and replaces the input with whatever it left behind when it exits 0. A non-zero exit, a missing temp file, an editor that can't be started, or an empty result all leave the input UNCHANGED — the last of those with no notice (a deliberate "never mind"), the rest with one.
- **Keys are now rebindable** via `$CONWAY_CONFIG_DIR/keybindings.json` (or `~/.conway/keybindings.json`), `{ "context": { "action": ["key", ...] } }` over the existing `prompt`/`transcript`/`permission_prompt`/`agents_panel`/`palette`/`settings` contexts and their existing actions. An entry a file supplies replaces that action's default keys wholesale, never merges with them; an unknown context, unknown action, unparseable key, or a key bound twice within one context fails to load, naming the exact entry at fault, rather than silently dropping it or partially applying the file. `/help` now shows the EFFECTIVE bindings (defaults as overridden by your file), and `docs/interactive.md` documents the full action vocabulary from the same table `/help` reads.
