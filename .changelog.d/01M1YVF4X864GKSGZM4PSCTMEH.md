### Added

- **`@`-mention file completion in the prompt, and a plain-`Tab` path completion fallback** — board item `01M1YVF4X864GKSGZM4PSCTMEH`. Typing `@` at a word boundary opens a live, fuzzy-filtered completion list of paths under `cwd` (or, with `--root` set, confined to that directory): `Up`/`Down` move the highlight, `Tab` or `Enter` inserts the highlighted path, and `Esc` dismisses the list (typing further inside the same `@`-token will not immediately reopen it). While composing `/fork`/`/spawn`, the identical `@` trigger completes against this session's own live agent ids/names instead — `/fork`/`/spawn @<agent>`'s existing addressing convention, reusing the same widget. The walk runs entirely off the render loop (spawned via `tokio::task::spawn_blocking`, reported back over its own channel the way the `/settings` providers section's background probe already is), so a slow or contended filesystem/`git` can never freeze the TUI; the overlay shows "scanning..." while a walk is in flight. In a git repository the walk shells out to `git ls-files --cached --others --exclude-standard` (honoring `.gitignore` for free, no new dependency), itself wall-clock bounded and killed if it overruns; outside one, a plain walk skips `.git`/`target`/`node_modules` under its own time budget. Either way it is capped by candidate count, says so in the overlay's own title when capped, and is cached per confinement root for 15 seconds so repeated `@`-mentions in one message do not each re-walk. A candidate containing a space is quoted on insert (`@"release notes.md"`) and parsed back out whole at submit time. A submitted prompt's `@`-mentions are sent unchanged as text, plus a clearly-delimited line naming every mentioned path, so the model reads them as references rather than ordinary prose; a mention opened by a bracketed paste (as opposed to typing) does not let a bare `Enter` silently accept a candidate instead of submitting, until the operator actually interacts with the list. New rebindable actions: `prompt.complete_path` (default `Tab`, plain-prompt path completion with no `@` involved) and a new `mentions` context (`navigate_up`/`navigate_down` default `Up`/`Down`, `accept` default `Tab`/`Enter`, `close` default `Esc`). See `docs/interactive.md`'s new "Mentioning files" section.
