### Added

- **`.conway/models.json` entries can now carry a `price`, and conway shows what a turn actually cost** — board item `01M1YVRS0K284H9QB32ZZW6D5G`. A `price` sub-object (`input_per_mtok`, `output_per_mtok`, optional `cache_read_per_mtok`/`cache_write_per_mtok`, `currency` — only `"USD"` is understood today) is optional per model; no bundled prices ship for any model, so a cost figure is only ever shown when an operator has actually priced the pair, never guessed. Where it's shown: the TUI's turn-end summary appends a `· $0.012`-style figure; a new optional `cost` status-line field shows the focused agent's cumulative session cost; `/context`'s header names the estimated (`≈`) cost of the next request at the focused model's input price; `conway sessions show --cost` prints a per-turn breakdown plus totals by model; one-shot `--output-format json` includes `usage.cost` when known. Every one of those five surfaces computes the figure through the same shared pricing function, so they can never disagree. A figure is marked `≈` whenever it could not apply a cache discount it had reason to believe exists (the backend didn't report cache accounting for the turn, or reported cache tokens with no configured cache rate) — see [providers.md](../docs/providers.md#per-model-pricing) for the full precedence and the currency-formatting rule (3 decimals at or above one cent, 4 below).

### Changed

- **`docs/providers.md`, `docs/interactive.md`, and `docs/sessions.md`** document the new `price` fields, the status line's `cost` field, and `sessions show --cost` respectively.
